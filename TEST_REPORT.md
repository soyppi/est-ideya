## Исправление публикации, версия 20261022-5

После сообщения пользователя о `permission denied for table ideas` обнаружен пропущенный вызов: настоящая форма создания в версии 4 всё ещё выполняла прямой INSERT. SQL-тест серверной функции не проверял подключение самой формы к этой функции. Исправлено: форма использует submit_idea с UUID запроса; прямого обходного INSERT при ошибке нет. Добавлены клиентская проверка делегирования формы и SQL-проверка публикации обычным пользователем при запрещённом прямом INSERT. npm test проходит.

В облачном PostgreSQL под authenticated с ID существующего подтверждённого пользователя роли user проверены публикация через RPC, повтор того же запроса без дубля, чтение своей новой идеи, комментарий, поддержка и её снятие. PASS, все тестовые изменения откатились через ROLLBACK. Прямой INSERT в текущем SQL-сеансе также разрешён, поэтому именно отказ с устройства пользователя этим прогоном не воспроизведён. Проверка в пользовательском браузере после обновления остаётся отдельным шагом.

Дата: 22 октября 2026. Предыдущая версия: 82da4af759afe84863656c7f16c675e2240dc8c0. Этот отчёт входит в новую проверяемую версию, её SHA доступен в main.

## Автоматические проверки

Команда: npm ci, npm test. Node.js 24.14.0, PGlite 0.3.14. Выполнено успешно, все группы PASS:

- Повторная установка схемы и миграций при широких исходных Supabase grants; права явно ограничены.
- Запрет самоповышения, подмены статуса, чужой идеи, физического удаления, подделки истории. Проверены администратор, модератор, обычный и неподтверждённый аккаунты.
- Чужое редактирование не меняет запись; своё новое разрешено; после рассмотрения возвращается ноль обновлённых строк.
- Второй одинаковый голос отклонён уникальным ключом; идемпотентный RPC не размножает голоса; снятие своего оставляет чужой.
- Разрешённый переход записывает событие; повтор не добавляет второе; недопустимый переход и пустое пояснение отклоняются.
- Скрытые идеи, комментарии, голоса и история не читаются обычным пользователем прямым запросом; модератор видит скрытое, восстановление возвращает идею.
- Неизвестная и пробельная категория, короткий заголовок, пробельное и слишком длинное содержимое отклоняются SQL CHECK.
- Повтор UUID публикации/комментария возвращает исходную запись.
- Демонабор восстановлен дважды: семь идей, шесть доступны гостю, пять статусов. Существующие реальные данные тестом не затрагиваются.
- Клиент: отсутствие конфигурации, отложенная авторизация без блокировки, поиск и экранирование, устаревшие ответы, адрес подтверждения и повторная отправка.

Настоящие SQL-правила проверены на временном PostgreSQL-движке PGlite с воспроизведёнными auth.users/auth.uid. Это не проверка доставки писем и настоящей конкуренции подключений. Для последней поставлен test-live.cjs с 8 одновременными голосами и 4 переходами; облачный запуск отложен до подготовки учебных аккаунтов владельцем.
