# Учебные аккаунты для жюри

Скопируйте файл в приватный документ. Заполненную копию с паролями НЕ загружайте в публичный репозиторий.

Сайт: https://soyppi.github.io/est-ideya/

| Назначение | Роль | Подтверждённый email | Пароль — только в приватной копии |
|---|---|---|---|
| Автор | user | Заполнить | Заполнить |
| Голосующий | user | Заполнить | Заполнить |
| Модератор | moderator | Заполнить | Заполнить |
| Другой участник | user | Заполнить | Заполнить |

Все четыре аккаунта разные и не содержат личных данных студентов. Назначение moderator выполняется администратором. Исходные примеры восстанавливает приватная копия demo_reset.sql с этими email. Проверьте каждый вход и передайте документ жюри по согласованному закрытому каналу.
